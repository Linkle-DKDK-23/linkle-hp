# SEO / AIO ロードマップ（v1.1・2026-11-18）

Linkle株式会社のコーポレートサイト（https://linkle.group）を、検索と AI 検索の両方から見つけてもらうための計画。
根拠は `research-seo.md`、出発点の数値は `03-baseline.md`。

## 1. 目的と、狙う検索

**目的**: 建設業（専門工事会社）の経営者・事務責任者が、業務システムを探したときに Linkle を見つけ、資料請求か相談に至ること。

| 優先 | 狙う検索語の型 | 受けるページ |
|---|---|---|
| A | {業種} 業務システム / 管理システム / システム開発（荷揚げ、足場、造園、鳶、防水、解体、内装、塗装） | `/industries/*`、`/works/*` |
| A | 建設業 業務システム 開発 / オーダーメイド | `/construction-dx` |
| B | 建設業 システム開発 | `/construction-dx` + 比較サイトへの掲載 |
| B | FDE / フォワードデプロイドエンジニア | `/service#fde` |
| C | 社名（Linkle株式会社 など） | `/`、`/about` |

狙わないもの: 「建設 システム」（他社の社名）、「足場 システム」「塗装 システム」（製品や設備を探す検索）。

## 2. 現在地

- 刷新前の28日間（10/20〜11/16）: 表示178回、クリック21回。**表示された検索語はほぼ社名だけで、建設・システム開発を含む語は0件**
- 2026-11-18 に刷新版を公開。全20ページが静的 HTML、構造化データ・サイトマップ・正しい404を設定済み
- GA4（Linkle HP）で資料請求とお問い合わせを `generate_lead` として計測中
- 開発事例5件（荷揚げ・足場は個別ページ）

## 3. 考え方

1. **AI 検索のための特別な仕掛けは、ほぼ要らない。** Google は、AI による回答に出る条件を「通常の検索に出ること」としており、llms.txt や AI 専用の記法を不要と明言している。効く根拠があるのは次の3つ
   - 通常の SEO（読める HTML、正しい会社情報、内部リンク）
   - 他社に書けない一次情報（数字と条件のある事例）
   - サイトの外での言及（比較サイト、企業データベース、取引先、報道）
2. **コラムを運用しないので、更新の柱は事例。** 新しい事例を載せるたびに、関連する業種ページも実例に書き換える
3. **ページを一度に増やさない。** 業種名を差し替えただけのページの量産は、Google のスパム判定の対象。Search Console で反応を見てから増やす
4. **順位は約束できない。** 下の目標は「この水準に届いていなければ打ち手を変える」ための目安

## 4. ロードマップ

担当: **L** = Linkle の方の作業（アカウント登録、社内確認、顧客への依頼）／ **C** = 開発側（Claude）で実施できる作業

### フェーズ1: 土台を固める（公開〜2週間）

検索エンジンと AI に、新しいサイトを正しく読ませる。

| # | 作業 | 担当 | 狙い |
|---|---|---|---|
| 1-1 | Search Console で主要ページのインデックス登録を確認・リクエスト（トップ、建設業向け、業種8、事例2） | C（確認）/ L（リクエストは画面操作） | 新しいページを早く読ませる |
| 1-2 | Bing Webmaster Tools に登録し、サイトマップを送信 | L（登録）/ C（設定） | ChatGPT の検索は Bing の索引を使うと報告されている。Google 以外への入口 |
| 1-3 | Google ビジネスプロフィールの登録・更新（カテゴリ、説明文、住所、サイト URL） | L | Google が公式に推奨。会社の取り違え防止 |
| 1-4 | 会社情報の表記統一（社名・住所・事業内容）。求人媒体、SNS、企業データベースの自己紹介を「システム開発会社／建設業の業務システム」に書き換え | L | サイトの外の情報を、新しい打ち出しに揃える |
| 1-5 | 構造化データの追加: WebSite、事例ページの Article、Organization の sameAs（GBP・SNS・求人媒体の URL） | C | 会社情報を機械に誤読させない |
| 1-6 | 会社概要ページの冒頭に「誰が・誰に・何をするか」を一文で明記。事例の数字を1文に収めた要約を各事例に追加 | C | 人にも AI にも引用しやすい形にする |
| 1-7 | AI 検索の現状を記録（下の「6. 計測」の質問リストを ChatGPT / Perplexity / Gemini / Google で実行） | C（質問リスト）/ L（実行） | 出発点を残す |
| 1-8 | guide.linkle.group / service.linkle.group から linkle.group へのリンクを確認・追加 | L または C | 自社サイト間の評価をつなぐ |

### フェーズ2: サイトの外に名前を出す（2週間〜2か月）

「建設業 システム開発」の1ページ目は、比較サイトと大手が占めている。そこに名前を出す。

| # | 作業 | 担当 | 備考 |
|---|---|---|---|
| 2-1 | 比較サイト・発注先紹介のうち、**無料で掲載できるもの**への申し込み | L | 有料のものは見送る。各サイトの無料枠の有無を確認する |
| 2-2 | 企業データベースの情報更新（Baseconnect など） | L | 無料で修正依頼できるものから |
| 2-3 | 紹介文の統一: 「建設業の専門工事会社向けに業務システムを開発。荷揚げ会社で受注から入金までの手作業を20回から4回に」 | C（文案）/ L（掲載） | サイトと同じ言い回しに揃える |

### フェーズ3: 中身を厚くする（1〜3か月）

Search Console の反応を見ながら、効いているところに足す。

| # | 作業 | 担当 | 条件 |
|---|---|---|---|
| 3-1 | 事例の詳細化: 造園・管工事・動画プラットフォームを個別ページに | L（内容の提供）/ C（制作） | 課題・つくったもの・結果が書ける事例から |
| 3-2 | 業種ページの追加（第2弾）。まず**管工事**（事例あり）。続いて表示が出ている業種の近縁 | C | 固有の内容が書ける業種だけ |
| 3-3 | 事業別ページの分割（`/service/system-development`、`/service/fde`、`/service/dx`、`/service/web`） | C | 「FDE」などでの流入を狙う。内容を各1,500字以上に |
| 3-4 | 「費用の考え方」「進め方」「無料の見本とは」のページ | C | 金額は出さず、何で決まるかを書く。AI 検索で最も聞かれやすい質問への答え |
| 3-5 | 業種ページの「想定する構成例」を、実例がある業種から実例に書き換え | C | 事例が増えるたびに |
| 3-6 | 表示回数はあるがクリックされないページのタイトル・説明文を改善 | C | Search Console のデータで判断 |

## 5. 目標（目安）

| 時期 | 見る数字 | 目安 |
|---|---|---|
| 2週間後 | インデックスされたページ数 | 20ページ中18以上 |
| 1か月後 | 社名以外の検索語での表示 | 0件 → 表示が出始める |
| 1か月後 | AI 検索での言及 | 社名を聞いたときに、正しい事業内容で答える |
| 3か月後 | 業種の検索語での平均順位 | 3業種以上で30位以内 |
| 3か月後 | 検索からのクリック | 月50回以上（刷新前は月21回） |
| 6か月後 | 業種の検索語での1ページ目 | 2業種以上 |
| 6か月後 | 資料請求 + お問い合わせ（検索経由） | 月に数件 |

検索ボリュームを計測していないため、クリック数と件数の目安は粗い。1か月後の実績で置き直す。

## 6. 計測

**毎週（自動で取得できる）**
- Search Console: 表示回数、クリック数、検索語（社名／社名以外）、ページ別、インデックス状況
- GA4: `generate_lead` の件数（資料請求／お問い合わせ）、流入元

**毎月（手動）: AI 検索での言及テスト**
次の質問を ChatGPT、Perplexity、Gemini、Google（AI による概要）で実行し、Linkle が出たか・内容が正しいかを記録する。

1. Linkle株式会社はどんな会社ですか
2. 建設業の業務システムを開発してくれる会社を教えてください
3. 荷揚げ会社の事務を効率化するシステムを作れる会社はありますか
4. 足場工事会社向けの管理システムを、既製品ではなく専用に開発したい
5. 造園会社の業務システムを開発している会社
6. FDE（Forward Deployed Engineer）を提供している日本の会社
7. 中小の建設会社が、紙と Excel の業務をシステム化するにはどこに頼めばよいですか

## 7. やらないこと

- llms.txt や AI 専用の記法への投資（効果を示す根拠がない。置くとしても10分で済む範囲）
- 業種名を差し替えただけのページの量産
- 根拠のない数字、順位保証をうたう業者への依頼、リンクの購入
- 金額の掲載（方針どおり）

## 8. 決まったこと（2026-11-18）

1. **比較サイトへの掲載は無料の範囲に絞る。** フェーズ2は、無料で登録・修正できる企業データベースと、無料掲載枠のある紹介サイト、プレスリリースの無料配信、取引先からの言及を中心にする
2. **Linkle 側の作業（L）は、発注者本人が担当する**
3. **週次で回す。** 毎週 `npm run seo:report` で数字を取り（`docs/seo/reports/`）、その場で次の1週間の打ち手を決める。月次の AI 検索テストも同じ場で行う
4. **造園・管工事・動画プラットフォームの事例はヒアリング中。** 情報が揃った順に個別ページ化する（3-1）

## 9. 週次の進め方

1. `npm run seo:report` を実行（Search Console・GA4・インデックス状況を取得）
2. レポートの「所見と次の打ち手」を書く
3. その週にやる作業を、フェーズの表から2〜3個選んで実施
4. 月の最初の週は、AI 検索の言及テスト（6章の7つの質問）も行う
