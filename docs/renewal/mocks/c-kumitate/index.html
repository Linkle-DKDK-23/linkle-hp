Parts ばらばらの事務

紙、Excel、LINE、電話。
事務が、ばらばらになっていませんか。

一つでも当てはまれば、システムで減らせる手間があります。

  • 紙を使っている

    発注書・依頼書・請求書が、紙とファイルで棚に。

  • Excelで管理している

    予定表・受注表・給与が別々のExcel。在庫もExcelやメモで。

  • LINEで1件ずつ送る

    翌日の現場を、職人ひとりずつにメールやLINEで。

  • 属人化している

    手順も単価も、ベテランの頭の中にしかない。

  • 連休が取れない

    担当者が休むと、請求も手配も止まる。

  • ミスや漏れが出る

    打ち直すたびに数字がずれる。送り漏れが出る。

  • 在宅で作業できない

    紙が事務所にあるので、行かないと進まない。

  • 新人の教育コストが高い

    どのExcelのどこに何を書くか、覚えるまで数か月。

それ、すべてシステムで解決して、
ひとつにまとめられます。

Build できること

受注から手配、請求まで。
一階ずつ、組み上げます。

1F手配

現場の手配を、自動で組む。

Excelで管理して、職人にLINEやメールで送っていた現場情報。誰をどの現場に配置するかまで自動で組み、翌日の現場が職人のスマホに届きます。

  • 配置を自動で組む
  • 全職人へワンタップ送信
  • 送り漏れは一覧で分かる
2F図面と材料

図面を渡せば、設計と必要な材料を自動で。

図面を取り込むと、設計と必要な材料の数量を自動で出します。そのまま、各現場に手配する職人の割り当てまでつながります。

  • 材料の数量を自動で算出
  • 在庫とつながる
  • 手配まで一続き
3F職人のスマホ

職人は、スマホを見るだけ。

集合時間・現場・注意事項がスマホに届く。「出発」「終了」をタップすれば、事務所の画面で進み具合が分かります。

  • 集合時間と現場が届く
  • 「出発」「終了」をタップ
  • 進み具合が事務所で見える
4F請求

1現場1回の入力で、明細も請求書も。

案件登録、職人に送る明細、請求書。同じ情報を何度も打ち直していた手間をなくします。1回入力すれば、すべてに反映されます。

  • 入力は1回
  • 計算は自動
  • 二重入力をなくす
RFひとつの台帳

すべてが、ひとつの台帳に。

案件・取引先・職人・単価・在庫を、一つの台帳で。誰が開いても同じ画面、どこからでも同じ情報。業務の流れは会社ごとに違うから、お話を伺って御社専用に0からつくります。

  • 誰が開いても同じ
  • クラウドで在宅でも
  • 御社専用に0から

Industries 業種から探す

足場も、造園も、荷揚げも。
その業種の業務システムを、専用でつくる。

同じ建設業でも、帳票も手配のしかたも業種ごとに違います。御社の業種の言葉で、業務の流れに合わせて開発します。

  • 01

    荷揚げ・揚重業務システム開発

    当日の人員手配、出面の集計、元請ごとの請求

  • 02

    造園業務システム開発

    年間管理契約、剪定スケジュール、作業履歴

  • 03

    鳶・土工業務システム開発

    出面管理、応援の手配、複数現場の班編成

  • 04

    防水業務システム開発

    材料の拾い、保証書の発行、定期点検の案内

  • 05

    解体業務システム開発

    マニフェスト、石綿調査の記録、重機の回送

  • 06

    内装仕上業務システム開発

    工種別の出来高、材料の発注、追加変更の記録

  • 07

    建築塗装業務システム開発

    現場調査から見積、仕様の記録、工程写真

  • 08

    足場管理システム開発

    部材の在庫、リースと回収、トラックの配車
