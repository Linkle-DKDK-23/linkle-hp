# HP刷新 ヒアリング結果（2026-11-18）

## 目的
- 「建設業 システム開発」「建設 システム」および「{業種名} システム」（足場・造園・塗装…建設系は全業種）で検索上位に表示される。AI検索（AIO）でも言及される。
- 現行サイトの「デザインに凝りすぎて内容が見えづらい」状態を解消する。ただしデザインは妥協しない（スクロールの概念を壊す／背景／開幕アニメーション／ディテール）。

## 決定事項
| 項目 | 決定 |
|---|---|
| 会社の顔 | 「建設業のDX・システム開発会社」と言い切る。Web制作はその一部（Web制作自体は業種を問わず受ける） |
| 業種ページ | 建設系は全業種を対象 |
| 実績 | 荷揚げ屋のDX化。1日4時間の事務工数を削減 |
| 金額 | HPには金額を出さない（900万→300万 等は不可）。「無料で見本をつくる」は金額ではないので掲載候補（要確認） |
| 数字 | 「顧客満足度99%」は削除。「メンバー20+」は残す |
| 資料 | https://guide.linkle.group/read.html（PDF風）をヘッダー・事業紹介から導線。閲覧情報を取れるようにする。service.linkle.group（LP風）も別サイトとして存在 |
| 技術 | Next.js へ移行（SEO/AIO 優先）。配信は S3 + CloudFront |
| コラム | 運用しない（固定ページで勝つ） |
| 問い合わせ | 電話番号なし。種別に「無料見本の依頼」「資料請求」を追加 |
| デザイン | 黒基調・WebGL の世界観は捨てて一新。ベースカラー #6ccaf1 とロゴは維持 |
| 素材 | 撮影なし。3D・イラスト・抽象表現で構成 |
| 進め方 | 急がない。段階公開可。実装前にデザイン方向性モック（2〜3案）で決定 |
| 計測 | Search Console は設定済みの見込み。GA4 含め API 経由で設定できる環境を用意する |

## 追加回答（2026-11-18）
- 荷揚げ事例: 顧客の掲載許可は未取得。社名・詳細は出せない（匿名での扱いは要確認）
- 「無料で見本をつくる」: 掲載する
- 資料の閲覧計測: 匿名のアクセス解析（どこまで読んだか）でよい。フォームは挟まない
- Search Console / GA4: サービスアカウント方式で進める。手順を渡す

## モック3案（a-sora / b-zumen / c-kumitate）へのフィードバック（2026-11-18）
- 3案とも「AI感」がある → 不採用。作り方から見直す
- 「建設業のDX・システム開発」を押し出しすぎ。**システム開発会社のHPであることが前提**。建設業は強みの一つとして扱う（当初の「建設業と言い切る」から修正）
- 1ページ構成ではなく、複数ページのコーポレートサイト

## 追加決定（2026-11-18 後半）
- デザイン: D案（輪）を軸にする。背景の波紋・3D粒子・横送りなどの演出を採用。粒子は控えめに
- 事業は4本: 業務システム開発 / FDE / DX支援・業務効率化 / Web制作
- トップ見出し: 「システムに、仕事を合わせない。」（調査は research-copy.md）
- FDE: 常駐、準委任契約、AI導入に限らず業務システム全般が対象
- 資料: 代表者名とメールアドレスを入力すると閲覧できる形にする（当初の「匿名の計測のみ」から変更）
