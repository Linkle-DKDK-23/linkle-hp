## 8. 実装エージェントへの申し送り（再審査後に残る事項）

1. **G12 の縦溢れ**（§7-1 反映後）: `GhostSection` の sticky 内で文字が 100dvh を超えるため、`overflow: hidden` を sticky 要素に必ず付ける。`tail` 行は上段が画面上端を超える場合は描画しない（DOM に残すと `span` 数だけ増える）。
2. **G22 の速度しきい値**: lenis の `velocity` は px/frame 相当。`> 6` で隠す、`< 1` が 150ms で復帰。トラックパッドの微小慣性で隠れ→復帰がちらつく場合は隠す側を `> 10` に上げてよい（復帰側は変えない）。
3. **G18 の registry 登録**: `div.light` の実 `offsetTop` ではなく設計の計算値（`section.top + 100vh`）で登録する。`ResizeObserver` の再計測時も同じ式を使う。
4. **G19 の高さ**: 白面は `height: 61vh` 固定。ビューポート高 < 900px では col2 を 22px/32px に落とす分岐を忘れない。最下行（©・`お問い合わせ`・`↑`）は `position: absolute; bottom: 40px` で置き、col2 の流れに依存させない。
5. 初回申し送り TOP5（ピルの窓クリップ / 左右タグラインのベースライン共有 / 配管の App 直下 fixed 1 本化 / NEXT PAGE の減衰 + 1 回発火 / 全 `useInView` に `root: wrapperRef`）は引き続き有効。

## 6. 実装エージェントへの申し送り

### 6.1 設計書の曖昧点・矛盾点

1. **G18 の DOM 構造**（矛盾・要修正）: §4 G18「外側 150vh + `div.light` に `margin-top: -100dvh`」は白面が最初からブランド面に重なりワイプしない。§5.0 の「`FooterSection` 200vh」に合わせ、`div.light` は負マージンなしの通常フローに置く。
