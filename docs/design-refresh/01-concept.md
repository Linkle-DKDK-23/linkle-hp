# B 案「Blueprint（設計図）」デザインコンセプト

対象: linkle 株式会社コーポレートサイト（React / CRA / Tailwind、6 ページ）
絶対枠: `docs/design-refresh/reference/lusion-reference.md`（§1 構造 13 セクション、§3 ギミック 22 項目、§5 チェックリスト 25 項目をすべて満たす前提）
本書の位置づけ: 構造・ギミック・レイアウト比率は仕様書どおり。B 案の独自性は「思想・色・比喩・フォント」の範囲に限定する。方眼・寸法線・座標ラベルは**装飾レイヤ**であり、lusion のセクション構成を置き換えない。

> 表記: 「G1〜G22」は仕様書 §3 のギミック番号。「§1-3」のように書いたときは仕様書 §1 のセクション番号 3（TEAM）を指す。
> テキストの引用は既存コードのコピーをそのまま使う（`src/pages/*`, `src/components/layout/*`）。改行位置・大文字化（CSS `text-transform`）・文節ごとの `span` 分割は「表示上の組み方」であり、文言の変更・追加ではない。

## 1. デザイン哲学 — Blueprint

**空間。** 黒は「何もない」のではなく、まだ線が引かれていない製図用紙である。全セクションの左右 5vw マージン、5 列の `+` クロスヘア、右端の縦インジケータ、それらは lusion がすでに置いている座標系であり、B 案はその座標系を**本当に座標系として読む**。黒面の下に極細（1px。主線は 10%、補助線は 5% の白 = §4.1 `--bp-grid-major` / `--bp-grid-minor`）の方眼を敷き、クロスヘアの列を主線、その 8 等分を補助線とする。方眼は何も主張しない。ただ、巨大文字が下端からせり上がるとき、タグラインが着地するとき、白いカードが 4〜8px ずつ階段になるとき、その「ずれ」が方眼に対して計測可能であることを示す。受託開発会社の仕事とは、ずれを測り、決め、揃えることだ。空間そのものが「私たちは精度で仕事をする」と語る。文字は語らない。

**色と材質。** 面色は 4 つしか持たない。黒 `#000`、ブランド面 `#6ccaf1`、白 `#fff`、そして次ページ帯の `#121416`。黒は墨、`#6ccaf1` は**青焼き（ブループリント）の紙面**そのもの、白はトレーシングペーパー、帯は図面を綴じる台紙。lusion の `#1a2ffb` がインクの青なら、B 案の `#6ccaf1` は紙の青であり、だからこそブランド面の上では文字・ロゴが黒に反転する（白文字はコントラスト 1.85:1 で本文に使えない。この物理的制約を思想に変える）。塗りのグラデーションはボタンにも面にも一切使わない。許すのは lusion と同じく液体（B 案では「配管を流れる液」）の内部だけで、そこはブランド色から深い水色 `#0b3a56` への一方向の流れとする。影も使わない。白いカードは面の色差だけで浮く。

**スケールとリズム。** lusion の 31 画面分のスクロールは、B 案では「図面帳を 1 枚ずつめくる」時間である。各セクションの左上に置かれる `[[ 001 ]]` は装飾ではなく**シート番号**で、セクションが進むごとに `002`, `003` と増える。プリローダーの巨大 3 桁カウンターは同じ書体（JetBrains Mono）で同じ役割を演じ、ページ遷移の `LOADING` は 5×7 ドットのプロッタが 1 点ずつ打つ。数字は常に 3 桁ゼロ埋め、常にモノスペース。巨大文字（23vw）と 11px のラベルの間には中間サイズをほとんど置かない。極大と極小の 2 極だけで組むのが lusion のリズムであり、B 案はその極小側を「計測器」で埋め、極大側を「図面上の唯一の主役」として孤立させる。

**構成とバランス。** 対角配置（左上／右下）、右上がりの階段カード、±1° の傾き。lusion が「手で置いた」ように見せる非対称を、B 案は「寸法線で確定した」ように見せる。カード群の上には幅を示す寸法線が 1 本走り、傾きは `1.0°` のラベルで正直に書かれる。粒子雲は**ワイヤーフレームの頂点群**であり、スクロールで頂点同士に稜線が結ばれてメッシュになり、その同じ地形データが TEAM 相当セクションでは発光する等高線として現れる。1 つのデータを頂点→メッシュ→等高線と 3 段階で描き分けることが、B 案の「モーフ」の意味だ。液体チューブは配管図のパイプで、管に沿って目盛りが刻まれる。

**階層。** 主役は各画面に 1 つ。ヒーローでは `LINKLE`、イントロでは文節ごとに立ち上がる 2 つの文、ブランド面では白いカード。それ以外（方眼、寸法線、座標ラベル、デコード文字）はすべて 50% 以下の不透明度に沈め、主役の邪魔をしない。装飾レイヤは「消しても構造が壊れない」ことを設計条件とし、逆に言えば装飾レイヤを消せばそのまま lusion の骨格が現れる。これが「同じ枠だが linkle の B 案だ」と分かる唯一の方法であり、そのためにすべての線・数字・目盛りは、熟練の製図者が引いたように、痛いほど正確に、しかし控えめに置かれなければならない。

## 3. ページ別セクションマップ

### 共通の枠（全ページ）

- **ヘッダー（固定）**: 左上ロゴ `Linkle`（22px、字間 0.08em、`text-transform: uppercase`）。右上に 円ボタン（46px、`#e6eef2`、アイコンは L 字ロゴ 18px、`/` へ）/ ピル `LET'S TALK •`（`#22272b`、白 13px、→ 既存ナビの `お問い合わせ` = `/contact`）/ ピル `MENU ••`（`#e6eef2`、黒 13px）。MENU は全画面オーバーレイ（黒面 + 方眼）に既存ナビ `ホーム` `会社概要` `サービス` `採用情報` `お問い合わせ` を 3 桁番号付きで縦組み。ピルの塗りは面に関わらず不変（G22）。
- **クロスヘア** 5 列（x = margin+8px から等間隔、中央列は画面中央）。B 案では中央列のみ**レジストレーションマーク**（十字 + 直径 12px の細円）。既定 y 49vh、TEAM 相当で 22vh、帯で 93vh。
- **方眼レイヤ**（黒面のみ）: 主線 = クロスヘア列、補助線 = 主線間の 8 等分。1px、主線 `rgba(255,255,255,.10)` / 補助線 `rgba(255,255,255,.05)`（§4.1）。ブランド面・白面には方眼を敷かない（青焼き紙・トレペは無地）。
- **スクロールインジケータ** 右端、溝 160px、ノブ 4×30px。黒面 / ブランド面 = 白ノブ、白面 = 黒ノブ。
- **面の順序** 黒 → ブランド `#6ccaf1` → 白 → 帯 `#121416`（S1）。
- **NEXT PAGE 巡回**: `/` → `/about` → `/service` → `/news` → `/recruit` → `/contact` → `/`。帯の次ページ名は既存文言: `会社概要` → `サービス` → `News` → `採用情報` → `お問い合わせ` → `ホーム`。
- **仮想スクロール**（G5）、**ページ遷移**（G21）、**プリローダー**（G1）は全ページ共通。
- 各セクション左上のシート番号 `[[ 0NN ]]` はページ内で 001 から連番。
- **低コントラスト文字（G12）の大きさ**: 各行が画面幅を 15% 以上超えるまで拡大する（下限 18vw）。90vh の高さクランプは行わず、縦は sticky 100dvh 内で溢れさせる（下段ベースライン bottom 6vh、上段は上端で見切れてよい。lusion 画像 22 の `CREATIVE` と同じ）。サブページの短い文字列（`働く` `環境` / `OUR` `MISSION` / `CONTACT` `US` 等）も**拡大で**画面幅を超えさせ、文言は差し替えない。

## 6. オリジナリティの説明

いずれも lusion の構造・ギミック・レイアウト比率を変えない「装飾レイヤ・色・比喩・書体」の範囲に留めている。装飾レイヤを非表示にすれば、そのまま lusion の骨格が現れる。

1. **方眼・寸法線・シート番号の装飾レイヤ。** 黒面の下に 1px の方眼（主線 = クロスヘア列、補助線 = 8 等分）を敷き、各セクション左上の `[[ 001 ]]` をシート番号として連番にする。カード群やヒーロー文字の周囲に寸法線と傾き値が現れる。lusion の「計測器ラベル」を主役に引き上げただけで、セクションの数・順序・面色は不変。
2. **青焼き反転 — ブランド面は「紙」。** lusion の `#1a2ffb` はインクの青だが、B 案の `#6ccaf1` は青焼きの紙面として扱う。結果としてブランド面上の文字・ロゴは黒に反転し（コントラスト上も必然）、白は巨大文字と NEXT PAGE 線にだけ残る。面色の数と順序は lusion と同一。
3. **1 つの地形データを 3 段階で描く。** 粒子雲 = 頂点群、スクロール後 = 稜線が結ばれた地形メッシュ、TEAM 相当 = 同じ地形の発光等高線。lusion の G2 / G9 の枠に「設計データが実装されていく」物語を載せる。
4. **配管としての液体チューブ、直角定規としての L。** チューブに 40px ピッチの目盛りを刻み、液をブランド色→深水色で満たす。プリローダーと遷移の L（1:3.1 + 2:1）は直角定規として読める。ピクセルアイコン = 5×7 ドット数字で、`LOADING` とカードの記号系を統一する。
5. **書体の組み合わせ。** Instrument Sans（欧文）+ JetBrains Mono（数字・ラベル）+ Zen Kaku Gothic New（日本語）。数字は常に tabular、3 桁ゼロ埋め。日本語は欧文より 1 段小さく組み、斜体行は `skewX(-10deg)` の擬似斜体で lusion の斜体位置を再現する。
