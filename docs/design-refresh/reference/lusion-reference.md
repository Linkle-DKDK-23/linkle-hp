## 2. 共通 UI 要素

- **ヘッダー**: 左上ロゴ（テキスト、中太サンセリフ、字間広め）。右上に 3 つ: 丸ボタン（波形アイコン、ライト）/ ピル `LET'S TALK •`（ダーク `#2b2e3a`、白文字、末尾にドット）/ ピル `MENU ••`（ライト `#e4e6ef`、黒文字、末尾に 2 ドット）。高さ ≈ 45px、角丸フル。ホバーで色反転。**仮想スクロールの速度に応じてピル群が縦に数〜30px ずれ、`overflow:hidden` の窓で上下端がクリップされる（速度連動のラグ）。停止で元位置に戻る。**
- **面ごとの色反転**: 黒面 → ロゴ白・ノブ白 / ブルー面 → ロゴ黒・ノブ白 / 白面 → ロゴ黒・ノブ黒。**ピルの塗りは面に関わらず不変**（ダーク+ライトの組で常にコントラストが取れる設計）。
- **クロスヘア `+`**: 画面に 5 列、細く小さいグレー。マージン内側 8px から等間隔、中央列は画面中央。縦位置は既定で垂直中央、セクションにより上（22vh）や下（93vh）へ移動する。
- **スクロールインジケータ**: 画面右端の縦線（高さ ≈ 150〜160px）にノブ。面の明暗で白/黒に反転。
- **カーソル**: 通常。ボタンホバーでの拡大は控えめ。
- **ラベル類**: 全て大文字、レタースペーシング広め、11–14px。`[[ 001 ]]`、`::::`、目盛りなど「計測器」的なモノスペース装飾。
- **番号**: 3 桁ゼロ埋め（`001`, `016`）。
- **ボタン**: ピル（角丸フル）か円。塗りは黒/白/ブルーの単色のみ。グラデーション無し。影無し。
- **余白**: 左右マージン ≈ 75px（≈ 5vw）。セクション間は 100vh 単位で非常に大きい（総スクロール ≈ 31 画面分）。
- **セクションのオーバーラップ**: 前セクションのテキストが灰色にフェードしながら残り、次セクションが重なって現れる（画像 20）。ハードカットはしない。

## 3. モーション言語（ギミック一覧 = 必ず再現する対象）

各項目の下の「実装」は React + CSS / Canvas / WebGL で再現する際のヒント。

1. **プリローダー**: 太めのプログレスバー + 巨大 3 桁カウンター（桁ロール）→ バーが 2 矩形に分裂して L 字に変形 → L が拡大回転してマスクワイプ。
   - 実装: カウンターは各桁を `0〜9` 縦並びの列にして `translateY(-n*1em)`（`overflow:hidden` + tabular-nums）。バー→L はバーと同寸の `div` 2 枚を `transform` でスライド・回転（Motion の `layout` か `keyframes`）。ワイプは全画面の固定レイヤに `clip-path: path()`（L 字パス）または `mask-image`（L 字 SVG）を当て、`scale()`+`rotate()` を進めて窓を広げる。窓の中は `backdrop-filter`/半透明白で「透かし」感を出す。
2. **WebGL 粒子雲ヒーロー**: 数千パーティクル、浮遊・呼吸、マウス追従、スクロールで別シーンへモーフ。
   - 実装: three.js `Points` か `InstancedMesh`（球）を 3,000〜8,000 個。位置は simplex noise で時間更新、マウスは `uniform` で反発力。シーン切替は目標位置バッファを 2 組持ち `mix(a, b, progress)` でモーフ。月面シーンは静止画テクスチャ + パーティクルに差し替えて良い（WebGL 不可の案は Canvas2D 円描画で代替）。
3. **巨大ブランド名の文字せり上がり**: 1 文字ずつ、回転しながら下端から入る（stagger）。
   - 実装: 文字を `span` 分割、親を `overflow:hidden`、各 `span` に `translateY(110%) rotate(±30deg)` → `0` を `transition-delay: i*80ms`、easing は `cubic-bezier(.2,.8,.2,1)`。`transform-origin` は左下/右下で交互に。
4. **文字のゴム変形→タグライン着地**: スクロール量に応じて文字がストレッチ・傾斜し、小さなコピーに置換される。
   - 実装: 巨大文字を SVG `<text>` にして `feDisplacementMap`（turbulence をスクロール進捗で強める）か、CSS `scaleX(1→3)` + `skewX` + `translateX` で右へ引き伸ばして `opacity` 0。同じ進捗でタグライン各行を `clip-path: inset(0 0 100% 0)` → `inset(0)` + 灰→白。ヒーローは `position: sticky` で 200〜300vh ピン留めし、`scrollProgress` を 0〜1 で共有。
5. **仮想スムーススクロール**: 慣性、lerp。セクションは 100vh 以上の「間」を持つ。
   - 実装: `@studio-freight/lenis`（`lerp: 0.08` 前後）を導入し、`requestAnimationFrame` で `lenis.raf`。自前なら `wheel` の `deltaY` を目標値に足し、`current += (target-current)*0.08` で `#ui` を `translate3d`。`html,body{overflow:hidden}` にする。
6. **単語ステージ出現 + 対角配置**の大テキスト。
   - 実装: 単語を `span` 分割し `IntersectionObserver` で `opacity/translateY` を `i*40ms` の stagger。`word-spacing: .4em`。左上ブロックと右下ブロックを `grid` の対角セルに置く。
7. **計測器ラベル**（`[[ 001 ]]`、ルーラー、ドット、デコード文字）。
   - 実装: モノスペース 11px。ルーラーは `repeating-linear-gradient` か `|....|` の文字列。デコード文字は `setInterval` 60ms でランダム英数字に置換し、指定文字へ順に確定。
8. **青い円形ボタン**（中央、矢印が回転）。
   - 実装: 84px の `border-radius:50%`、`position: fixed` で画面中央（クロスヘア列と共有座標）。矢印 SVG を `rotate(scrollProgress*180deg)`。
9. **発光等高線**の WebGL 背景。
   - 実装: フルスクリーン `ShaderMaterial` で `fbm` ノイズを `fract(h*N)` でスライスし、線幅を `smoothstep` で細く、`bloom`（`UnrealBloomPass` か 2 パスの blur 加算）で発光。Canvas2D 代替: `marching squares` 等高線をライン描画 + `shadowBlur`。
10. **3 段ロゴマーキー**（逆方向交互）。
    - 実装: 各段はロゴ列を 2 回複製し `translateX(0→-50%)` の `animation: marquee 40s linear infinite`、偶数段は `animation-direction: reverse`。`will-change: transform`。
11. **3 桁ゼロ埋め番号リスト**。
    - 実装: `String(i+1).padStart(3,'0')` をモノスペース列に、`border-bottom: 1px dotted`。
12. **巨大低コントラスト背景文字**（`CREATIVE STUDIO`）。
    - 実装: `font-size: 18vw`、`color: #15161c` on `#05060a`（塗り。`-webkit-text-stroke` は使わない）、`white-space: nowrap`、`overflow: hidden` の親から左右にはみ出す。上段 italic。
13. **液体チューブ／メタボール**が中央を縦に貫いてセクションをまたぐ（ブルー面で最も強い）。
    - 実装: DOM 案は SVG `filter: feGaussianBlur(stdDeviation 10) → feColorMatrix(alpha 19 -9)` の goo フィルタを、縦長 `rect` + 複数 `circle` に当て、スクロールで円を下へ移動→千切れる。WebGL 案は raymarching の SDF（capsule + sphere の `smoothmin`）で屈折・ハイライト。`position: fixed` で画面中央 x に固定し、セクションをまたいで持続させる。
14. **白カード 4 枚 + ピクセルアイコン + 上下反転ミラー・タイトル**、微妙な傾き。
    - 実装: `grid-template-columns: repeat(4, 1fr); gap: 32px`、各カードに `transform: translateY(-i*6px) rotate(var(--tilt))`（`--tilt` = −0.5°〜1.5°）。ミラーは同じタイトル要素を `transform: rotate(180deg)` で下部に再掲。アイコンは 4×4 の `grid` で塗るピクセル SVG。
15. **`+ ×` パーティクル噴水**。
    - 実装: Canvas2D で 300〜600 個の `+`/`×` グリフを、頂点から `vx = (rand-0.5)*spread, vy = -speed` + 重力で放つ。フレームごとに `fillText` か小さな線 2 本。スクロール進捗で放出量を増減。
16. **`CONTINUE TO SCROLL` ピル**（スクロール促し）。
    - 実装: 250×53px 白ピル、`position: fixed; bottom: 58px; left: 50%`。両端の `↓` を `translateY` で上下に揺らす。セクション離脱で `opacity: 0`。
17. **文字二重分割のホバー/スクロール入れ替え**（`Let's work together!`）。
    - 実装: 各文字を `span.char` にし、中に同じ文字を 2 つ縦並び（`overflow:hidden; height:1em`）。ホバー/進入で `translateY(-100%)` を `i*20ms` stagger。
18. **面のワイプ転換**（ブルー→白）。
    - 実装: ブルー面を `position: sticky` の全画面 `div` にして、次セクションの白面が上へ重なる（`z-index` 上位、`translateY(100vh→0)`）。境界は直線のまま。液体レイヤだけ遅らせて `opacity` を落とす。
19. **フッターの行マスク・リビール**（下から上、時間差、文字バラけ）。
    - 実装: 行ごとに `overflow:hidden` の `div` を作り、中の `span` を `translateY(110%)→0`、`transition-delay: row*90ms`。文字バラけは各 `span.char` に `translateY(random 0〜8px)` の追加遅延を与え、最後に 0 へ揃える。
20. **末尾オーバースクロールで NEXT PAGE プログレス → 自動遷移**。
    - 実装: 仮想スクロールが最大値に達した後の `wheel deltaY` を累積（`progress += deltaY/1500`、非入力時は減衰）。`progress` を 150px の線の `scaleX` に反映（ライム `#c1ff00`）。`progress >= 1` で遷移アニメ → `navigate('/next')`。
21. **ページ遷移: L 字の窓が旧ページを閉じ込め縮小回転 → 黒 → ピクセル `LOADING`**。
    - 実装: 旧ページのスクリーンショットは不要。全画面固定レイヤ（黒）に L 字の `clip-path`/`mask` で「穴」を開け、穴を `scale(6→1)` + `rotate(-8deg→0)` で縮める。穴の下の旧ページは白オーバーレイで退色。完了後に `LOADING` を 5×7 ドット行列（`grid`）の `div` に描き、各ドットを `i*15ms` で点灯。その後 `navigate()` → 遷移先でプリローダー（#1）を再生。
22. **ヘッダーピルの遅延フェードイン**、面の明暗でロゴ/ピルの色が反転、スクロール速度でピルが縦ずれ。
    - 実装: ピル群を `overflow:hidden` の窓に入れ、初回は `translateY(100%)→0` を巨大文字の後（≈ 1.2s 遅延）。速度連動は `velocity = target-current` を `translateY(clamp(velocity*0.3, -30, 30)px)` に。ロゴ色は現在セクションの `data-theme`（dark/blue/light）で `color` を切替（`mix-blend-mode: difference` は使わない。ピルは固定色）。

## 4. linkle への適用ルール（全案共通の枠）

- **テキスト内容は既存サイトのまま**（`src/pages/*` の日本語コピー、会社情報、フォーム項目、ナビ項目）。追加してよいのは lusion にある UI ラベル相当（例: `SCROLL TO EXPLORE`, `CONTINUE TO SCROLL`, `NEXT PAGE`, `MENU`）のみ。
- 6 ページ構成（/ /about /service /news /recruit /contact）は維持。ルーティング・フォーム・ニュース JSON の機能は壊さない。
- 「L」字ロゴのギミックは linkle も頭文字が L なのでそのまま活かせる（`Linkle` の L）。L の比率（縦 1:3.1 + 横 2:1、太さ共通）は踏襲する。
- ブランドカラー `#6ccaf1` をどう扱うかは各案の「思想」で決める（lusion のブルー `#1a2ffb` の役割を置換するのが基本線）。ただし **面色は黒 / ブランド色 / 白の 3 つに限定**し、4 色目の面を増やさない。
- フォントは Aeonik（商用）そのものは使えない。近い骨格のオープンフォント（例: Manrope / Plus Jakarta Sans / Urbanist / Sora / Instrument Sans / Geist / Familjen Grotesk）+ モノスペース（IBM Plex Mono / JetBrains Mono / DM Mono / Space Mono）+ 日本語（Noto Sans JP / Zen Kaku Gothic New / Murecho / BIZ UDPGothic）。**Inter・Roboto・Arial・system-ui は禁止**（frontend-design スキル準拠）。案ごとにフォントを変える。
- 日本語の巨大文字は横幅が出ないため、ヒーローの「画面幅いっぱい」はローマ字ブランド名（`LINKLE`）で行い、日本語コピーはタグライン以降に使う。
- 「redesign-existing-projects」スキルの禁止事項（純黒 `#000` 面、等高 3 カラム、汎用カード影、Lucide 一辺倒）は lusion の観察事実が優先: **純黒面・4 枚カード・影なし面差カードは lusion 準拠として許可**。それ以外の同スキルの指摘（ホバー/フォーカス/ローディング状態、`min-height: 100dvh`、`transform` のみでアニメ）は従う。
